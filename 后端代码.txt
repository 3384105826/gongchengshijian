2.1 窗口分割检测.py - 核心检测算法
----------------------------------------------------------------------
【功能定位】实现滑动窗口目标检测与结果合并

【关键函数】
├── sliding_window_detection(model, image, window_size, overlap_ratio, conf_threshold)
│   - 功能：使用滑动窗口进行目标检测
│   - 参数：模型、图像、窗口大小(默认1024)、重叠比例(默认0.25)、置信度阈值(默认0.3)
│   - 返回：所有检测结果列表，包含mask、box、conf、class

├── merge_detections(detections, iou_threshold)
│   - 功能：合并重叠的检测结果（非极大值抑制）
│   - 参数：检测结果列表、IoU阈值(默认0.5)
│   - 返回：去重后的检测结果

├── calculate_iou(box1, box2)
│   - 功能：计算两个边界框的交并比
│   - 返回：IoU值(0-1)

└── apply_segmentation_to_image(image, detections)
    - 功能：将分割结果可视化到图像上
    - 返回：标注后的图像

【算法流程】
1. 将大图像按滑动窗口分割成1024x1024小块
2. 对每个窗口进行YOLO推理检测
3. 将检测结果坐标转换回原图坐标系
4. 使用IoU合并重叠检测框
5. 在原图上绘制分割掩码和边界框

2.2 训练模型new.py - 模型训练后端
----------------------------------------------------------------------
【功能定位】YOLOv11模型训练与优化

【关键函数】
└── train_yolo_model(model_path=None, use_gpu=True)
    - 功能：完整的模型训练流程
    - 参数：模型路径、是否使用GPU

【训练参数配置（防漏检优化）】
├── epochs: 100          # 训练轮数
├── imgsz: 1280          # 图像尺寸
├── batch: 2             # 批次大小
├── conf: 0.15           # 降低置信度阈值，提高召回率
├── optimizer: 'AdamW'   # 优化器
├── cos_lr: True         # 余弦学习率调度
└── patience: 30         # 早停耐心值

【数据集配置】
- 数据路径：loutongtxt_滑动裁剪1280 overlap=0.2/data.yaml
- 输出路径：训练结果漏铜/漏铜1280_防漏检优化

2.3 pyqt.py - 完整应用后端（含数据库）
----------------------------------------------------------------------
【功能定位】带用户认证和数据持久化的完整后端

【DatabaseManager类 - 数据库管理】
├── connect()                    # 连接MySQL数据库
├── _create_tables()             # 创建用户表和检测结果表
├── register_user(username, password, email)  # 用户注册
├── verify_user(username, password)           # 用户登录验证
├── save_detection_result(...)   # 保存检测结果到数据库
├── get_all_results()            # 获取当前用户所有检测结果
├── get_defect_details(result_id) # 获取缺陷详情
└── delete_result(result_id)     # 删除检测结果

【数据库表结构】
├── users表（用户表）
│   ├── id INT PRIMARY KEY
│   ├── username VARCHAR(50) UNIQUE
│   ├── password VARCHAR(255)
│   ├── email VARCHAR(100)
│   └── created_at DATETIME

├── detection_results表（检测结果表）
│   ├── id INT PRIMARY KEY
│   ├── user_id INT (外键关联users)
│   ├── image_name VARCHAR(255)
│   ├── total_defects INT
│   ├── detection_time DATETIME
│   ├── window_size VARCHAR(20)
│   ├── overlap_ratio FLOAT
│   └── output_path VARCHAR(500)

└── defect_details表（缺陷详情表）
    ├── id INT PRIMARY KEY
    ├── result_id INT (外键关联detection_results)
    ├── defect_index INT
    ├── confidence FLOAT
    ├── class_name VARCHAR(100)
    ├── bbox_x1/x2/y1/y2 FLOAT
    └── center_x/center_y FLOAT

【YoloDetectThread类 - 异步检测线程】
├── 功能：在后台线程中执行检测，避免界面卡顿
├── 信号：update_file_progress, update_batch_progress, process_done
└── 处理流程：加载模型 → 遍历文件 → 滑动窗口检测 → 保存结果 → 存储数据库

三、后端技术栈
======================================================================
